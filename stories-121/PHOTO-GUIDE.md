## 其餘 36 張照片上傳方式

1. 從自己的 Instagram／iPhone 相簿挑選 16 × 3＝48 張原始照片；每國以廣角風景、人物或生活、歷史景點作為搭配。
2. 優先將照片轉成 JPG，單張盡量低於 400 KB、長邊 1600 px 左右。
3. 把照片命名成下表指定名稱（完全小寫）；同一國依 `-1`、`-2`、`-3` 順序。
4. 到 GitHub 儲存庫 `rogeryangct/travel-itineraries` 的 `stories-121/photos/` 上傳。若目錄尚不存在，可先在 GitHub 建立該目錄並上傳；也可以將照片交給 ChatGPT 協助加入網站。
5. GitHub Pages 自動更新後，親友重新整理公開網址，即可看到照片。

**注意**：不建議直接連結 Instagram CDN 圖片（可能過期或被阻擋）；網站圖檔應放在 GitHub 儲存庫供公開瀏覽。**不要上傳護照、房號、訂房資料或其他私人影像。**
