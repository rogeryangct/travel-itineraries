# R & A 共用行程模板 v1

2026-09-10 定版，以 Sarajevo → Žabljak 行程目前已核准的版面為準。模板與網站一起保存在 GitHub；未填寫的範例不列入公開國家或行程目錄。

## 固定版面

- R & A 精簡置頂品牌；國家、今天、收藏、旅行工具、搜尋共用導航。
- 國家以英文顯示，中文名稱可供搜尋；國家簡稱與探索國家標題保持小尺寸。
- 行程頁：麵包屑、日期範圍、行程名稱、日期選單、必要路線重點、每日詳細安排、費用、導覽與來源。
- 行程工具列只有日期選單。不要增加副標題、頂部查核橫幅、分享、搜尋、大字、列印按鈕、出發清單或旅程筆記面板。
- 每站提供時間、介紹、移動方式與時間、費用幣別／單位、地圖，以及有資料時的官方連結和預約資訊。
- 景點按鍵一律標示「導覽」；內容含現場看點、歷史背景、相關故事與實用提醒，提供返回行程連結。
- 每日保留雨天替代、延誤刪減安排；費用和來源區保留實際查核日期。

## 新增流程（由助理執行）

1. 沿用 country.json、trip-entry.json、trip-detail.json，先查核旅行資料再填寫；占位日期與文字不可直接發布。
2. 已存在國家只新增行程；新國家加入 source/catalog.json。跨國行程用同一份內容，countries 填入所有相關國家 id。
3. 完整內容保存到 source/content/<trip-id>.json，entry.content 指向它。既有行程與穩定 id 保留。
4. entry.days 與 detail.days 的 id、日期、順序一致。設定正確 IANA 時區；跨時區日可用 day.timeZone 覆蓋，讓「今天」準確跳轉。
5. map 填查核過的 Google Maps 位置；來源填完整 HTTPS 與實際 checked 日期。未知票價標「待確認」，不當成零；天氣說明區分季節資訊和短期預報。不要公開私人訂房碼或門鎖資訊。
6. 用 build.py 的 render_structured 共用渲染器產生版面，不為新國家複製另一套 CSS/JavaScript。
7. 執行 python3 build.py，核對日期、內部連結及來源。index.html 與修改的來源檔一起提交 main，保留 .nojekyll。
8. 驗證 GitHub Pages 部署成功及公開頁面，再回覆網址。使用者不需要手動上傳。

未來的請求只需提供國家、日期與旅遊需求；助理沿此規格新增內容。此偏好不代表網站會自行在背景查核或更新資料。

## 內容總覽區（選配）

trip-detail 可加入 overview 陣列，置於每日行程前。每區使用 id、title、paragraphs、links（title/url），可加 table（headers/rows）。適合天氣、道路比較、補貨與預約；仍沿用共用版型，不新增功能工具列。數值須標明查核日期、估算或未確認，不能把舊年度價格當成可預訂報價。
